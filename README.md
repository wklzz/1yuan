# 1yuan / 星核收集者

这是一个自包含的浏览器 3D 小游戏原型，入口文件是 `index.html`，不依赖 PHP 或后端框架。

## 游戏玩法
- 使用 `W/A/S/D` 或方向键移动玩家飞船。
- 按住 `Shift` 可短暂加速。
- 在 60 秒内收集全部 6 个星核。
- 避开红色巡逻无人机；每次碰撞会扣除 6 秒。

## 运行方式
可以直接双击 `index.html` 在浏览器打开，或使用任意静态文件服务器，例如：

```bash
python3 -m http.server 8000
```

然后打开：

```text
http://127.0.0.1:8000/index.html
```

## 实现内容
- Three.js 渲染 3D 场景
- 第三人称跟随相机
- 玩家移动与冲刺
- 可收集目标
- 敌人巡逻与碰撞惩罚
- HUD、开始/结算界面与胜负逻辑
